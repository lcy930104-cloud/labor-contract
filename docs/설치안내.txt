전자근로계약서 앱 설치 안내
================================

0. 구성
   - 근로계약서앱 폴더 안의 파일을 전부 그대로 올립니다 (index.html, manifest.webmanifest, sw.js, 아이콘 png 4개).
   - 올린 뒤 https://…/index.html 로 접속하면 첫 화면에 "앱으로 설치하기" 안내가 뜹니다.
     안드로이드: 브라우저 메뉴(⋮) > 홈 화면에 추가 / 앱 설치
     아이폰: Safari 공유 버튼 > 홈 화면에 추가
     PC 크롬: 주소창 오른쪽 설치 아이콘
   - 홈 화면 아이콘으로 열면 주소창 없이 앱처럼 열리고, 인터넷이 잠깐 끊겨도 화면은 뜹니다.
   - 근로자는 설치할 필요 없습니다. 카카오톡으로 받은 링크를 누르면 브라우저에서 열립니다.
   - 파일을 고친 뒤 다시 올리면 앱을 닫았다 열 때 자동으로 새 버전이 적용됩니다.

1. 파일 올리기 (필수)
   - 컴퓨터에서 index.html을 더블클릭해 열면 주소가 file:///… 로 시작합니다. 이 상태에서 만든 링크는 근로자 휴대폰에서 열리지 않고, 앱 설치도 되지 않습니다.
   - 근로계약서앱 폴더를 통째로 인터넷에 올려야 합니다. 가장 쉬운 방법:
     (a) Netlify Drop: https://app.netlify.com/drop 접속 > 가입(무료) > 근로계약서앱 폴더를 끌어다 놓기 > 바로 https://xxxx.netlify.app 주소가 생김 (index.html은 주소 끝에 안 붙여도 열립니다)
     (b) GitHub Pages: github.com 가입 > 새 저장소(Public) > 폴더 안 파일 전부 업로드 > Settings > Pages > Branch: main 저장 > https://아이디.github.io/저장소명/
     (c) 회사 홈페이지 관리자(호스팅 업체)에 폴더 업로드 요청
   - 올린 주소로 접속해서 사용합니다. 반드시 https 주소여야 앱 설치와 오프라인 기능이 동작합니다 (Netlify, GitHub Pages는 기본 https).

2. 설정 바꾸기
   - 메모장 등으로 index.html을 열어 위쪽 "설정" 부분의 따옴표 안만 고칩니다.

   channelChatUrl : 카카오톡 채널 1:1 채팅 링크. 세무회계삼강 채널 주소(https://pf.kakao.com/_ecByG/chat)가 이미 들어 있습니다.
   kakaoJsKey     : (선택) 카카오 디벨로퍼스(developers.kakao.com) > 내 애플리케이션 > 앱 추가 > 앱 키의 "JavaScript 키".
                    같은 화면의 플랫폼 > Web 에 파일을 올린 도메인(https://회사도메인)을 등록해야 합니다.
                    채우면 "카카오톡으로 보내기"가 카카오톡 공유 창(친구/채팅방 선택)으로 바로 열립니다.
   firebase       : (선택, 짧은 링크 모드) 아래 3번 참고.

3. 짧은 링크 모드 (Firebase, 무료)
   설정하지 않으면 계약 내용이 링크 안에 들어가서 링크가 700~1,000자 정도로 깁니다.
   설정하면 링크가 "…#k7f3x2abcd" 처럼 짧아지고, 근로자가 서명하면 사업주가 같은 링크를 다시 열기만 해도 서명 완료로 보입니다.

   3-1. https://console.firebase.google.com 에서 "프로젝트 추가" (이름 자유, 애널리틱스는 꺼도 됨)
   3-2. 왼쪽 메뉴 빌드 > Firestore Database > 데이터베이스 만들기 > 위치 asia-northeast3(서울) > "프로덕션 모드"로 시작
   3-3. Firestore의 "규칙" 탭에 아래 내용을 그대로 붙여넣고 "게시"

   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /contracts/{id} {
         allow get: if true;
         allow list: if false;
         allow create: if request.resource.data.keys().hasOnly(['data', 'status', 'createdAt'])
                       && request.resource.data.status == 'pending'
                       && request.resource.data.data is string
                       && request.resource.data.data.size() < 20000;
         allow update: if resource.data.status == 'pending'
                       && request.resource.data.status == 'signed'
                       && request.resource.data.data == resource.data.data
                       && request.resource.data.keys().hasOnly(['data', 'status', 'createdAt', 'sig', 'signedAt'])
                       && request.resource.data.sig is string
                       && request.resource.data.sig.size() < 20000;
         allow delete: if false;
       }
     }
   }

   3-4. 왼쪽 위 톱니(프로젝트 설정) > 일반 > 내 앱 > "앱 추가" > 웹(</>) 선택 > 등록
        나오는 firebaseConfig 에서 apiKey 와 projectId 두 값을 복사
   3-5. index.html 의 firebase: { apiKey: '여기', projectId: '여기' } 에 붙여넣고 다시 올리기

   참고: 규칙 때문에 링크(문서번호)를 아는 사람만 해당 계약서를 읽을 수 있고, 목록 조회·삭제·내용 수정은 아무도 할 수 없습니다.
         서명은 한 번만 기록됩니다.

4. 사용 흐름
   사업주: 새 계약서 작성 > 링크 만들기 > "카카오톡으로 보내기" (또는 링크 복사) > 근로자에게 전송
   근로자: 링크 열기 > 내용 확인 > 서명 > "카카오톡으로 보내기" 또는 "PDF 보내기"로 회신
   사업주: 서명된 링크 열기 (짧은 링크 모드에서는 원래 링크 그대로) > PDF 저장 > 근로자에게 교부, 필요 시 채널로 보내기
